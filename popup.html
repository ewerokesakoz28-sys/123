01
Accounts → Account settings

Выберите режим отправки прямо в блоке Account settings. Для конкретного аккаунта откройте All bundles и задайте доступные бандлы.

02
AI — если используется

Сохраните ключи и выполните Test Connection до выбора AI Mode, AI Dialog или генерации адреса покупателя.

03
Create New Bundle

Для каждой пары площадка + страна нужен совместимый Bundle. На Review все обязательные пункты должны иметь статус Ready.

04
Проверка первого письма

Используйте Preview First Email, затем Send отправьте тест на собственный адрес. Проверьте текст, язык, ссылки, HTML/PDF и QR.

05
VVS

Сначала сохраните настройки площадки кнопкой Save Settings. Запуск использует сохранённые пресеты, а не несохранённые поля формы.

06
Контроль

Следите за статусом операции, History и Logs. При сомнительном результате сначала проверьте Gmail Sent и только потом повторяйте.

Не начинайте массовую отправку сразу после настройки.Безопасная последовательность: Apply & check → Review → Preview First Email → тест на свой адрес → проверка History → запуск VVS или Auto Reply.

01
Send — обязательный тест

Выберите Bundle, укажите email продавца, точное название и цену. Имя, фото и ссылка объявления необязательны, но повышают точность шаблона.

02
Что использует Send

Письмо отправляется по текущему режиму Gmail. Перед нажатием проверьте Bundle и Initial source в сводке.

03
VVS — порядок полей

Введите ключ, выберите Platform, затем Countries и только после этого Filters. Смена площадки меняет доступные страны и фильтры.

04
Диапазоны и даты

Минимум не должен превышать максимум. Registration вводится как DD-MM-YYYY; максимальная дата требует минимальную.

05
Save Settings обязателен

Сохраните каждую площадку отдельным пресетом. Порядок сохранённых пресетов определяет порядок обработки.

06
Start, Pause и Stop

Start начинает цикл. Pause временно удерживает продолжение. Stop завершает работу безопасно; текущая операция может закончиться перед остановкой.

Новая площадка не участвует в запуске, пока для неё не создан пресет.Нажмите Save Settings и убедитесь, что площадка появилась в списке пресетов. Для каждой страны в сохранённых пресетах должен существовать Bundle с точно такой же площадкой и страной.
Export VVS Settings сохраняет только настройки отбора.После Import проверьте площадки, страны и фильтры перед запуском. Ключ и Bundles этим файлом не заменяются.

01
AI Assistant

Добавьте ключи, нажмите Save AI и Test Connection. AI-функции не готовы, пока тест подключения не завершён успешно.

02
AI Buyer Test

Выберите готовый Bundle либо Custom test. Generate Greeting начинает тест; Send as Seller имитирует ответ продавца; Reset Test очищает тестовый диалог.

03
Auto Reply

Сканирует непрочитанные диалоги отдельно в каждом включённом Gmail. Интервал задаётся в секундах; безопасное значение по умолчанию — 20.

04
Manual Reply — известный диалог

Откройте нужную цепочку в правильном Gmail. Оставьте Product Data пустыми: расширение попытается найти контекст и Bundle автоматически.

05
Manual Reply — нет контекста

Выберите Bundle и Reply step, затем заполните данные товара вручную. Не смешивайте данные другого объявления с открытым диалогом.

06
Отключение одного диалога

В History используйте Disable Auto-Reply для конкретной переписки. Это безопаснее, чем выключать Auto Reply для всех аккаунтов.

Во время Manual Reply не переключайте Gmail-вкладку или письмо.Дождитесь окончательного статуса отправки. Если результат неясен, проверьте Sent и History до повторной попытки.

01
Platform & Payment

Введите понятное уникальное имя, выберите площадку, затем страну и доступный Payment Service. Не меняйте площадку после заполнения остальных шагов.

02
Первое сообщение

Templates — свои тексты, по одному на строку, или JSON-файл. AI Mode генерирует первое письмо сам.

03
Initial Source

В режиме Templates софт берёт один из сохранённых текстов. В AI Mode язык первого письма сохраняется для дальнейших ответов.

04
Reply Chain

Scheduled AI отвечает продавцу, сразу отправляет уведомление об оплате и затем прикладывает HTML/PDF-шаблон деталей платежа.

05
Ссылка, PDF и QR

Шаблон, который должен получить платёжную ссылку, обязан содержать {link} или {qrCode}. Проверьте HTML/PDF и Preview QR с тестовой ссылкой.

06
Review & Test

Откройте каждый Required и заполните поле. Preview First Email должен показать правильный текст до сохранения.

После сохранения Bundle выполните реальный тест через Send.Preview проверяет структуру, но только тестовое письмо на свой адрес подтверждает правильность Gmail, вложения, ссылки, языка и отображения шаблона.
Bundle Manager сохраняет только Bundles.Export Bundles не включает Gmail-аккаунты, лимиты и History. После Import откройте каждый Bundle, проверьте Review и протестируйте отправку.

01
Stats

Initial — первые письма. Unique replies — только наш первый успешно отправленный ответ в новом диалоге; следующие сообщения той же цепочки не учитываются. Conversion рассчитывается по этим значениям.

02
History filters

All показывает всё; Send и Reply разделяют операции; Needs review собирает случаи, которые требуют ручной проверки.

03
Данные записи

Сверьте получателя, Gmail-аккаунт, товар, Bundle и тип события. Для chain смотрите Started, Completed или Failed step.

04
Действия History

Copy URL копирует исходные данные. Create Payment Link создавайте один раз для нужной записи.

05
Logs

Содержит события Gmail, Compose, очередей, повторных попыток и подтверждения доставки. Refresh обновляет список; Clear Logs не очищает History.

06
Экспорт и очистка

Export CSV сохраняет History для анализа. Clear удаляет историю из интерфейса — выполняйте очистку только после сохранения нужных данных.

Не нажимайте отправку повторно только из-за таймаута или закрытого popup.Сначала откройте папку Sent именно того Gmail u/N, затем найдите запись в History и изучите Logs. Повтор допустим только когда письма действительно нет.

01
Индексы Gmail

u/0, u/1 и далее — это адреса в URL Gmail внутри одного Chrome-профиля. Каждый индекс должен открывать ожидаемый аккаунт.

02
Apply & check

Сохраняет список и по очереди открывает только новые или неготовые индексы, проверяя вход, Gmail-адрес и Compose. Check all принудительно перепроверяет весь список.

03
Enabled и состояние

В отправке и Auto Reply участвуют только включённые подходящие аккаунты. Исправьте login required или verification до запуска.

04
Bundle Routing

All bundles разрешает аккаунту любой совместимый Bundle. Selected only ограничивает его отмеченными Bundles; пустой список исключит аккаунт из такой отправки.

05
Режимы отправки

Round-robin распределяет получателей по очереди. Round-robin pool использует независимые очереди аккаунтов. Broadcast отправляет каждому получателю с выбранного числа аккаунтов; 0 означает все доступные.

06
Daily send limit

Лимит применяется отдельно к каждому Gmail-аккаунту; 0 означает без лимита. Reset сбрасывает счётчики всех аккаунтов, но не удаляет History.

Структура аккаунтов защищена во время активной очереди.Для изменения количества, Enabled или Routing сначала остановите Send, VVS и Auto Reply. Ошибочный аккаунт можно проверить отдельно кнопкой Continue / Check; свежий Ready повторно не проверяется при старте VVS.
